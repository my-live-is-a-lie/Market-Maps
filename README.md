# Market Maps

تطبيق أندرويد يساعد في العثور على أقرب المحلات التي تبيع ما تحتاجه في منطقتك.

## الفكرة

عندما تريد شراء شيء معين (مثل بطارية ريموت) ولا تعرف أين يوجد المحل المناسب في منطقتك، يساعدك هذا التطبيق على:

- رؤية المحلات على خريطة
- البحث عن منتج وإظهار أقرب المحلات التي تبيعه
- إضافة محلات جديدة بسهولة (مفتوح للجميع حالياً)
- مزامنة البيانات على السحابة ليشارك الجميع في تحديثها

## التقنيات المستخدمة

- **لغة البرمجة**: Kotlin
- **واجهة المستخدم**: Jetpack Compose + Material 3
- **الخريطة**: Mapsforge (أونلاين + أوفلاين بعد التحميل)
- **قاعدة البيانات**: Firebase Firestore
- **الحد الأدنى لـ SDK**: 26

## ما تم إنجازه

- شاشة أول استخدام (GPS أو اختيار محافظة/منطقة)
- خريطة تفاعلية + إضافة محل بضغط مطوّل
- تصنيفات هرمية للمحلات
- بحث مع ترتيب حسب الأقرب + أسهم تنقل بين النتائج
- تعديل وحذف المحل
- مزامنة Firebase
- تحميل خريطة مصر للأوفلاين + تبديل Online/Offline
- علامات ملوّنة حسب نوع المحل
- بناء APK تلقائي عبر GitHub Actions

## كيفية تحميل ملف APK وتثبيته

### الطريقة 1: بعد أي رفع جديد على main
البناء يبدأ تلقائياً.

### الطريقة 2: تشغيل يدوي
1. افتح المستودع: https://github.com/my-live-is-a-lie/Market-Maps
2. اضغط تبويب **Actions**
3. من القائمة اليسرى اختر **Build Debug APK**
4. اضغط **Run workflow** ثم **Run workflow** مرة أخرى للتأكيد
5. انتظر حتى تصبح الحالة خضراء (نجح)
6. اضغط على آخر تشغيل → في الأسفل **Artifacts** → حمّل **MarketMaps-debug**
7. فك الضغط عن الملف ثم ثبّت `app-debug.apk` على هاتفك

> ملاحظة: قد يطلب الهاتف السماح بتثبيت تطبيقات من مصادر غير معروفة — هذا طبيعي لنسخ التطوير.
