# Market Maps

تطبيق أندرويد يساعد في العثور على أقرب المحلات التي تبيع ما تحتاجه في منطقتك.

## الفكرة

عندما تريد شراء شيء معين (مثل بطارية ريموت) ولا تعرف أين يوجد المحل المناسب في منطقتك، يساعدك هذا التطبيق على:

- رؤية المحلات على خريطة
- البحث عن منتج وإظهار أقرب المحلات التي تبيعه
- إضافة محلات جديدة بسهولة (مفتوح للجميع حالياً)
- مزامنة البيانات على السحابة ليشارك الجميع في تحديثها

## التقنيات المستخدمة

- **لغة البرمجة**: Kotlin
- **واجهة المستخدم**: Jetpack Compose + Material 3
- **الخريطة**: Mapsforge (تعمل بدون إنترنت بعد التحميل)
- **الحد الأدنى لـ SDK**: 26
- **إدارة الحالة**: ViewModel + StateFlow

## حالة المشروع

النسخة الأولية قيد التطوير.

### ما تم إنجازه حتى الآن:
- إعداد هيكل المشروع الأساسي

### الخطوات القادمة:
1. إضافة شاشة الخريطة (Mapsforge)
2. إضافة المحلات
3. البحث
4. الربط مع Firebase

## كيفية بناء الـ APK

1. اذهب إلى تبويب **Actions** في هذا المستودع
2. اختر Workflow البناء
3. اضغط **Run workflow**
4. بعد انتهاء البناء يمكنك تحميل ملف الـ APK من الـ Artifacts
